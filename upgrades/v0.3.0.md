# v0.3.0

相对 `v0.2.0`：便携包支持从 GitHub Release 一键升级。

## 变更

- 新增双端升级脚本：Windows `upgrade.bat` + `upgrade.ps1`；macOS `upgrade.command`
- 脚本从 latest Release 自动下载匹配当前系统的 `material-tags-catalog-*-{os}-{arch}.zip`，停服后合并解压到当前部署目录
- 合并时不覆盖已有 `.env`；升级前备份为 `.env.bak.upgrade`
- 支持 `-y` / `--yes` 跳过确认；可选 `CATALOG_UPDATE_REPO`、`GITHUB_TOKEN` / `GH_TOKEN`
- 文档同步一键升级 SOP（portable-dist-ci / README / 包内 README.txt / FAQ）

## 升级注意

- **首次升到本版**仍需手动下载 `v0.3.0` zip 并合并解压（旧包尚无 `upgrade.*`）；之后可用包内脚本一键升级
- 推荐路径：停服务 → 合并解压本版 zip（勿删整目录）→ 双击 `start.bat` / `start.command`
- 有网后可用：`upgrade.bat` / `upgrade.command`（或加 `-y`）；升级后仍需手动启动并打开 `/health`，确认 `version` 为 `0.3.0`
