# v0.1.0

素材标签索引服务首个可分发 MVP。

## 新增

- 扫描合并 `*.material-tags.json` 为 `material-tags-catalog.jsonl`（原子写、单条容错）
- 常驻服务：文件监听（debounce）+ 定时全量兜底 + BuildLock pending 合并
- HTTP：`GET /health`、`GET /v1/catalog`、`GET /v1/catalog/meta`、`POST /v1/catalog/rebuild`
- CLI：`serve` / `build` / `status`；`--version` 与 `/health.version`
- Win / macOS 便携包：GitHub Actions 打 tag 自动打包并发布 Release

## 说明

- 正式索引源为配置的 `CATALOG_ROOT`（素材盘），非本仓库目录
- 发版版本号以 Git tag 为准，CI 注入进程序
- 网络盘上 watchdog 可能漏事件，请保持定时重建开启
