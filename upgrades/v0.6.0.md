# v0.6.0

相对 `v0.5.0`：认 `.material_index` 父目录原媒体，并支持扫描排除目录与合法 orphan 标签清理。

## 变更

- 标签位于 `.material_index/` 时，可在直接父目录按同 stem 白名单猜原媒体；旧同目录布局不变
- 新增 `SCAN_EXCLUDE_DIR_NAMES`：按目录名任意深度排除扫描（文档示例 `000-回收站`）
- 合法 orphan（校验通过但无原媒体）默认物理删除旁车标签；`PURGE_ORPHAN_TAGS=false` 可关回仅 skip
- 契约、`.env.example`、CLI/常驻 workflow 与 builder / watcher / 测试同步

## 升级注意

- 可用包内 `upgrade.bat` / `upgrade.command`（或 `-y`）一键升级；或停服后合并解压本版 zip（勿删整目录，保留 `.env`）
- 升级后需**重建 catalog**；若盘上有「无原媒体」旁车，默认会在 rebuild 时被 purge，只读盘请先设 `PURGE_ORPHAN_TAGS=false`
- 需要排除回收站等目录时，在 `.env` 配置 `SCAN_EXCLUDE_DIR_NAMES`
- 升级后手动启动，打开 `/health` 确认 `version` 为 `0.6.0`
