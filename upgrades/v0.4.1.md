# v0.4.1

相对 `v0.4.0`：修复 Windows 便携包启动首屏中文乱码，并在日志中输出版本号便于确认当前运行版本。

## 变更

- `start.bat` 启动前自动执行 `chcp 65001`，切 UTF-8 代码页，减少首屏中文提示乱码
- 服务启动日志新增 `catalog-service version=...` 一行，升级后可直接在日志确认运行版本

## 升级注意

- 可用包内 `upgrade.bat` / `upgrade.command`（或 `-y`）一键升级；或停服后合并解压本版 zip（勿删整目录，保留 `.env`）
- 升级后手动启动，打开 `/health` 确认 `version` 为 `0.4.1`
