# v0.8.1

相对 `v0.8.0`：Agent 检索 playbook 补充可选技能安装分流，并登记 feature-dev 开发闭环索引。

## 变更

- playbook 增加 §11「可选：安装技能」：给出 `huyuan-ai-media-resource-finder-master` 安装命令；主路径仍为纯 HTTP curl，未装技能可继续按手册执行，冲突以本服务 playbook 为准
- `serve` Agent 段、`doc_index`、PRD-00008 R1-04 同步：允许文末可选技能指针，仍禁止写死盘前缀 / 内网 IP
- 新增 [`docs/workflows/feature-dev-loop.md`](../docs/workflows/feature-dev-loop.md)，并在 `AGENTS.md` / `doc_index` 挂上 `/team:feature-dev`（S1→S2→S3；本流程禁发版）
- playbook HTTP 回归测试改为禁止写死前缀/IP，允许正文出现技能安装指针

## 升级注意

- 可用包内 `upgrade.bat` / `upgrade.command`（或 `-y`）一键升级；或停服后合并解压本版 zip（勿删整目录，保留 `.env`）
- 升级后手动启动，打开 `/health` 确认 `version` 为 `0.8.1`；Agent 可读：`http://<host>:<port>/v1/docs/llm-media-search-playbook`（含 §11）
