# v0.9.0

相对 `v0.8.2`：catalog 消费上游 schema v4 口播全文 `subtitle`，可用原话短句检索；search 结果不回传全文。

## 变更

- 入库透传 `subtitle`：rebuild 后 JSONL 行带出口播全文；旧标签缺键 / 坏类型写 `""`，不 skip
- `GET /v1/catalog/search` 将 `subtitle` 纳入 AND 子串匹配（权重 +1）；仅口播原话出现的 token 也能命中
- search 的 `items[]` 与 OpenAPI `CatalogItem` **省略** `subtitle`，避免访谈全文撑爆 Agent 上下文；全量 `GET /v1/catalog` 仍带该字段
- 契约 / serve / playbook 同步：可复制口播 curl（如 `q=跑遍了整个武汉`）；写明历史 JSONL 无键须成功 **rebuild** 后才可按口播搜到

## 升级注意

- 可用包内 `upgrade.bat` / `upgrade.command`（或 `-y`）一键升级；或停服后合并解压本版 zip（勿删整目录，保留 `.env`）
- 升级后须成功跑一轮 rebuild（常驻 startup / 定时 / `POST /v1/catalog/rebuild`），旧索引行才带 `subtitle` 键；未 rebuild 时仅口播词会 0 命中
- 存量盘在上游重新 `write_tags` 成 v4 之前，多数素材 `subtitle` 仍为空，不承诺回填旧 `*.material-tags.json`
- 升级后手动启动，打开 `/health` 确认 `version` 为 `0.9.0`
