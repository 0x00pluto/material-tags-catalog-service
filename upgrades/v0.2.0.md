# v0.2.0

便携包版本化命名与原地升级约定。

## 变更

- 便携包 zip / 顶层目录名带版本：`material-tags-catalog-0.2.0-{os}-{arch}.zip`（例：`material-tags-catalog-0.2.0-windows-amd64.zip`）
- 文档化原地合并解压升级；发布包不含 `.env`，合并解压可保留现场配置
- Windows：局域网访问说明（`HOST=0.0.0.0`）；`start.bat` 关闭 CMD 快速编辑；服务端关闭彩色日志，减轻控制台「乱码」

## 升级注意

- 先停服务，再合并解压到现有部署目录；勿删除整个文件夹后再解压（否则会丢掉 `.env`）
- 历史 `v0.1.0` 附件仍为无版本文件名；本版起请按带 `0.2.0` 的文件名下载
- 升级后打开 `/health`，确认 `version` 为 `0.2.0`
