# v0.8.0

相对 `v0.7.1`：HTTP Agent 检索 playbook 按本实例渲染；常驻启动改为后台重建并支持 watch 启动静默。

## 变更

- 新增 `GET /v1/docs/llm-media-search-playbook`：返回本服务检索手册（`text/markdown`）；按本次请求注入 `api_base`，可选 `FILE_BROWSER_BASE` 注入 `file_base`（未设则标明未配置）
- 新增 Agent 手册模板 [`docs/workflows/llm-media-search-playbook.md`](../docs/workflows/llm-media-search-playbook.md)；与外部技能解耦，不写死内网默认盘地址
- 常驻 `serve`：startup 全量重建改后台线程，先 listen 再建索引；新增 `WATCH_STARTUP_QUIET_SEC`（默认 10）抑制启动期 watch 噪声二次全量
- 单次 `build_catalog` 内目录 listing 缓存，减轻网络盘猜媒体开销
- 便携包打包时将 playbook 拷至 `catalog-service/docs/workflows/`；`.env.example` / 契约 / serve 文档 / `doc_index` 同步

## 升级注意

- 可用包内 `upgrade.bat` / `upgrade.command`（或 `-y`）一键升级；或停服后合并解压本版 zip（勿删整目录，保留 `.env`）
- 若需在 playbook 中写出下载前缀，在 `.env` 配置 `FILE_BROWSER_BASE`（无尾斜杠）后重启
- 升级后手动启动，打开 `/health` 确认 `version` 为 `0.8.0`；Agent 可读：`http://<host>:<port>/v1/docs/llm-media-search-playbook`
