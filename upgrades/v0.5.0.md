# v0.5.0

相对 `v0.4.1`：索引侧贯通 schema v2 媒体元数据，并跳过猜不到白名单原媒体的孤儿标签。

## 变更

- 猜不到白名单原媒体时不再写入 catalog；`meta` / rebuild 拆分暴露 `skipped_no_media` 与 `skipped_invalid`
- 索引与 `GET /v1/catalog/search` 透传可选字段：`width` / `height` / `duration_s` / `aspect_ratio` / `orientation`（V1 或缺省为 `null`；坏类型不拖垮入库）
- 契约、builder / search / API 与测试同步；补充开发一键脚本 `dev-serve.sh` / `dev-test.sh`

## 升级注意

- 可用包内 `upgrade.bat` / `upgrade.command`（或 `-y`）一键升级；或停服后合并解压本版 zip（勿删整目录，保留 `.env`）
- 升级后需**重建 catalog**，新字段与「无原媒体不入索引」才会生效
- 升级后手动启动，打开 `/health` 确认 `version` 为 `0.5.0`
