# v0.7.0

相对 `v0.6.1`：search 支持可选路径前缀过滤，并加固 Windows CMD 快速编辑假死防护。

## 变更

- `GET /v1/catalog/search` 新增可选重复参数 `path_prefix`（多值 OR）：按 `tags_path` 目录边界收窄范围；响应回显 `path_prefixes`；非法路径 / 超限 → 400；OpenAPI 与契约 / serve workflow 同步
- Windows：服务进程内关闭控制台「快速编辑」（日志可见 `console quick-edit disabled`）；`start.bat` 失败时警告；FAQ 补充排查

## 升级注意

- 可用包内 `upgrade.bat` / `upgrade.command`（或 `-y`）一键升级；或停服后合并解压本版 zip（勿删整目录，保留 `.env`）
- 调用方可用 `path_prefix` 先定项目再搜；相对路径须相对 `CATALOG_ROOT`，与 catalog 行 `tags_path` 字面一致
- 升级后手动启动，打开 `/health` 确认 `version` 为 `0.7.0`；Windows 看启动日志是否出现 `console quick-edit disabled`
