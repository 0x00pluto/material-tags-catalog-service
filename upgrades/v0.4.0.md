# v0.4.0

相对 `v0.3.0`：常驻服务增加 catalog 关键词检索，找素材不必再拉全量 JSONL。

## 变更

- 新增 `GET /v1/catalog/search`：参数 `q`（必填）、`limit`（默认 20，上限 100）、`offset`
- 每次请求扫描当前 `material-tags-catalog.jsonl`：多词 **AND** 子串匹配 `title` / `description` / `keywords`
- 字段加权排序（keywords +3 / title +2 / description +1；响应**不**返回 score）；同分按 `stem` 升序
- 响应含 `query`、`tokens`、`limit`、`offset`、`total_matched`、`items`（行字段与既有契约一致）
- 非法/空 `q` → 400；catalog 缺失 → 404；无命中仍 200（空列表）；坏行跳过
- 找素材主路径改为 search；全量 `GET /v1/catalog` 仍用于导出/备份/小库调试
- 契约与 serve workflow 补充检索规则与 Agent「构造 q → search → 精选」两段式说明

## 升级注意

- 可用包内 `upgrade.bat` / `upgrade.command`（或 `-y`）从 latest Release 一键升级；亦可停服后手动合并解压本版 zip（勿删整目录，保留 `.env`）
- 升级后手动启动，打开 `/health` 确认 `version` 为 `0.4.0`
- 试用：`curl -s 'http://127.0.0.1:8787/v1/catalog/search?q=关键词&limit=5'`；OpenAPI 见 `/docs`
