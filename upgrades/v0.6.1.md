# v0.6.1

相对 `v0.6.0`：修复 Windows 一键升级在服务未运行时误失败。

## 变更

- `upgrade.ps1` 停服改为 `Get-Process` / `Stop-Process`（`SilentlyContinue`）；进程不存在时继续下载合并，不再被 `taskkill`「没有找到进程」中止

## 升级注意

- **当前仍是 0.5.0 / 旧 `upgrade.ps1` 的机器**：包内脚本尚未含本修复，请先任选其一：
  1. 手动下载 `material-tags-catalog-0.6.1-windows-amd64.zip`（或 `0.6.0`）合并解压到部署目录后再用新脚本；或
  2. 临时改本机 `upgrade.ps1` 的 `Stop-CatalogService`（见发版沟通 / FAQ），再跑 `upgrade.bat` 升到本版
- 可用包内 `upgrade.bat` / `upgrade.command`（或 `-y`）一键升级；或停服后合并解压本版 zip（勿删整目录，保留 `.env`）
- 升级后手动启动，打开 `/health` 确认 `version` 为 `0.6.1`
